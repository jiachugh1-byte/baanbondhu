# BaanBondhu 🌊 - Community-Powered Disaster Response for Assam

> Baan = Flood, Bondhu = Friend. Your friend during floods.

### The Problem
During Assam floods, people can't find:
- Where is safe shelter?
- Where is boat / NDRF help?
- Who needs help nearby?

Everything is scattered on WhatsApp, no real-time map.

### Our Solution
**One live map where anyone can:**
1. Click RED ALERT - share live location + loud siren for rescue
2. See SAFE ZONES (green) and DANGER ZONES (red) 
3. Mark "I NEED BOAT" or "I HAVE BOAT TO HELP"
4. Works even in low network

### Tech Stack
HTML, CSS, JavaScript, Leaflet Maps, Browser Geolocation API

### How to Use
1. Open website
2. Allow location
3. Click "My Exact Location" to see yourself on map
4. In emergency, press RED button
